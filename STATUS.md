# PuriCat — feature status

What is built, and how each part is known to work. The overview, downloads and screenshots are in [README.md](README.md); how things were tested is in [TESTING.md](TESTING.md).

> **Status: early development.** Phase 1 (runnable foundation) is complete; Phase 2 (database connectivity), Phase 3 (editing), Phase 4 (SQL and schema) and Phase 5 (AI) are partially complete. This build can connect to MySQL and PostgreSQL, browse tables and **filter their rows**, **edit data in tables that have a primary key** (spreadsheet-style, staged until Save), load a block copied from a spreadsheet, or a **CSV or Excel file**, with the **Smart Paste wizard** (INSERT / UPDATE / UPSERT matched on a unique key, previewed before anything runs), **run SQL in query tabs** (each tab on its own connection, with a row-impact guard, a row cap, Stop, history, and export to CSV / JSON / XLSX), and **chat with an AI** through a Claude Code or Codex CLI you have installed and signed in to. By default the AI is given the schema (names and types, never rows) and **no tools**: it only writes text, and SQL it suggests runs only when you open it in a query tab and run it yourself. You can turn on **database tools** for it: it can then look up the structure of the database in front and — only if you allow rows — run read-only queries; a change is a proposal that PuriCat runs only after you have read and approved it. The tools are verified with Claude Code; **no Codex turn with tools has been observed**. This build cannot create or alter schema objects through a form, import more than 10,000 rows at once, tunnel over SSH, connect to SQL Server, or take backups. **Not ready for production data.** The macOS download is signed with a Developer ID and notarized.

## Feature status

Labels used across the docs:

- **Implemented & verified** — in the code and exercised by a test or check that passed (see [TESTING.md](TESTING.md)).
- **Implemented, not yet verified** — in the code, but no test or run has confirmed it.
- **Planned (Phase N)** — not in the code.
