One record per major choice. Each has: Status, Context, Decision, Alternatives considered, Consequences, Licensing.

Status values: **Accepted** (decided; the record says whether it is implemented) and **Proposed** (the intended direction; not implemented, may change when the phase starts).

| [0021](0021-backups-with-dump-tools.md) | Backups as built: `mysqldump` / `pg_dump` found on the computer and chosen for the server; the password in an option file of the user's own or in the environment, never an argument; a file named only after the tool's closing line was seen or `pg_restore` listed it; one job per database with the folder of the user's choice; a per-user LaunchAgent that starts the app's own executable for scheduled runs; retention that deletes only scheduled backups, after a newer one was kept. No restore, no encryption | Accepted | `mysqldump` 9.3.0 with MySQL 9.3.0 and `pg_dump` 16.13 with PostgreSQL 16.13: every backup restored into a second database and compared; through the window on both; one scheduled run started by launchd with the app closed (development build). MariaDB, older versions, passwords and TLS: not verified |
